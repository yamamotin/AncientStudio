# Diretivas para agentes

## Conclusão de tarefas

- Ao concluir uma tarefa, integre as alterações na `main` por um pull request da branch de trabalho, depois de executar as verificações pertinentes.
- Sincronize com a `main` e resolva conflitos com segurança na branch de trabalho antes do merge. Não descarte alterações de outros agentes.
- Confirme que o pull request foi mesclado e, em seguida, exclua a branch de trabalho remota. Exclua a branch local apenas quando isso for permitido e seguro no ambiente da sessão.
- Se instruções explícitas mais recentes, regras do ambiente, falhas nas verificações ou proteções do repositório impedirem alguma etapa, não contorne essas restrições; informe o que ficou pendente.
